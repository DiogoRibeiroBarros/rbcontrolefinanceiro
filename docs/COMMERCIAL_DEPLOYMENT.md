# Checklist de publicação comercial

- [ ] Repositório público/privado criado como `PandaRaivoso/rbcontrolefinanceiropremium`.
- [ ] Domínios HTTPS do portal, API, checkout e webhook configurados.
- [ ] PostgreSQL, SMTP, segredos e chave privada Ed25519 armazenados fora do Git.
- [ ] Chave pública e URLs preenchidas nos artefatos de release.
- [ ] Termos, privacidade, suporte e política de cancelamento publicados.
- [ ] Produtos e preços criados no provedor e webhook testado com assinatura real.
- [ ] Instalador Windows e APK assinados, com hashes publicados.
- [ ] Testes de migração, downgrade, revogação, offline e exclusão de conta executados.
- [ ] Backup e procedimento de restauração ensaiados.
